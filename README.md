# YLY . 51 الأقصر — DIY Face Swap

موقع بسيط (Static — من غير أي Backend أو مفتاح API) بيدّي المستخدم:
1. صورة الشخصية يحملها
2. برومبت جاهز ينسخه
3. يروح بنفسه لأي أداة ذكاء اصطناعي (ChatGPT / Gemini / Grok) ويعمل الصورة بحسابه هو

## تشغيله محليًا (للتجربة بس)

مش محتاج npm ولا أي تثبيت. أي طريقة تشغّل ملفات static تكفي، مثلاً:

```
python3 -m http.server 8080
```

وبعدين افتح `http://localhost:8080`

## النشر (عشان يفتح لأي حد بأي لينك)

### الطريقة الأسرع: GitHub Pages (ببلاش تمامًا)

1. اعمل حساب GitHub (لو مالكش)
2. اعمل Repository جديد، وارفعله كل ملفات المشروع ده (اسحب وأفلت الملفات في الموقع، أو استخدم Git)
3. من إعدادات الـ Repository (Settings) → Pages
4. من "Source" اختار الفرع (Branch) اللي رفعت عليه (غالبًا `main`) والفولدر `/root`
5. احفظ، واستنى دقيقة أو اتنين
6. هيديك لينك شكله كده: `https://<username>.github.io/<repo-name>/`
7. ده اللينك اللي تشاركه مع أي حد في الإيفنت، هيفتح من أي موبايل على طول

### بدائل تانية سريعة (لو حابب)
- **Netlify Drop**: روح `app.netlify.com/drop` واسحب فولدر المشروع كله، هيديك لينك فورًا من غير حتى حساب GitHub
- **Vercel**: شبه Netlify، بس محتاج حساب

## إضافة شخصيات جديدة

1. حط صورة الشخصية الجديدة في فولدر `characters/`
2. افتح `characters-data.js` وضيف عنصر جديد في المصفوفة `CHARACTERS` بنفس الشكل، وحط وصف دقيق للملابس/الخلفية عشان البرومبت يطلع مضبوط
